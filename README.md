# APC Library OPAC Front-End Backup

## Overview

This repository serves as a backup of the APC Library Online Public Access Catalog (OPAC) front-end interface.

The purpose of this repository is to preserve the HTML, CSS, and JavaScript source code of the OPAC interface for documentation, reference, and future restoration if needed.

> **Note:** This repository contains only the front-end code. Backend services, databases, APIs, authentication, and server-side configurations are not included.

## Purpose

This repository is maintained to:

- Preserve the OPAC front-end source code.
- Provide a reference for future maintenance.
- Assist in restoring the interface if necessary.
- Document the structure of the OPAC user interface.

---

## Backup Method

The code in this repository was collected from the existing OPAC interface for archival and documentation purposes.

Where available, HTML, CSS, JavaScript, and other front-end resources have been saved in their respective folders.

---

## Limitations

This repository **does not include**:

- Database
- Backend source code
- Server configuration
- Authentication services
- API endpoints
- Library management system data

As a result, this repository alone cannot fully restore the operational OPAC system.

---

## Maintenance

Whenever the OPAC interface is updated:

1. Update the affected files.
2. Commit the changes to the repository.
3. Add a brief description of the changes.

Example commit message:

```
Updated Search page layout
```

or

```
Modified navigation menu styling
```
